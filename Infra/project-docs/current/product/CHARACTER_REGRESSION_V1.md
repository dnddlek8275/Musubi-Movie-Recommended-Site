# 대표 캐릭터 대화 회귀 평가 1차

기준일: 2026-08-08

## 평가 구성

대표 캐릭터 10명을 다음 말투 유형에서 선정했다.

- 마석도, 장첸
- 토니 스타크, 피터 파커, 데드풀
- 헤르미온느, 알버스 덤블도어
- 골룸, 엘사, 브루스 웨인

각 캐릭터에 동일한 네 상황을 적용해 실제 GPU API `/chat` 응답 40건을 수집했다.

1. 원인이 제시되지 않은 감정 표현
2. 구체적인 일상 갈등과 전달 문장 요청
3. 대화 이력이 있는 후속 질문
4. 검증되지 않은 다른 인물과의 관계 질문

평가셋과 실행기는 다음 파일에서 관리한다.

- `AI/eval/character_regression_cases_v1.json`
- `AI/eval/run_character_regression.py`

## 기준선에서 발견한 문제

- 일상 문장의 `친구`를 원작 질문으로 오인해 10건 모두 캐릭터 RAG가 실행됐다.
- `너라면 지금 뭐라고 답할 거야?`가 대화 이력을 무시하고 상황을 다시 묻는 답으로 교체됐다.
- `OO에 대해 어떻게 생각해?`를 관계 질문으로 감지하지 못해 관계를 창작했다.
- 실용적인 조언에 캐릭터성을 과하게 적용해 강제력·영역·대가·위협 표현이 생성됐다.
- 50명 목록 밖 인물인 안나·울버린은 이름 감지가 되지 않아 관계 생성 방어를 우회했다.

## 반영한 수정

- 일반적인 `친구`, `가족` 단어만으로 원작 RAG를 실행하지 않는다.
- 대화 이력이 있으면 짧은 후속 질문도 앞선 사용자 상황을 사용한다.
- `OO에 대해 어떻게 생각해?`를 관계 질문으로 분류한다.
- 관계 질문은 기본적으로 근거 없음 상태이며, 전용 `relation` 청크가 검색된 경우에만 관계 답변을 허용한다.
- 등록 목록 밖 인물의 관계 질문도 동일한 근거 정책을 적용한다.
- “뭐라고 말할까?” 요청에는 실제로 전달할 수 있는 문장을 먼저 제시한다.
- 캐릭터성은 전달 문장의 내용이 아니라 짧은 말투 포장에만 적용한다.
- 강제력·영역·끝장·폭력 조언 탐지 기준을 평가기에 추가했다.

## 최종 결과

- 실제 API 평가: 40건
- 예상하지 않은 RAG 사용: 0건
- 자동 검출된 폭력·강압·상담 클리셰·말투 혼용: 0건
- 대화 이력이 있는 두 대표 요청을 별도로 재검증해 상황 재질문이 사라진 것을 확인했다.
- 등록 목록 밖 관계 질문을 별도로 재검증했다.
  - 데드풀–울버린: 관계 생성 없음, `rag_used=false`
  - 엘사–안나: 관계 생성 없음, `rag_used=false`

## 해석과 한계

- 자동 검출 0건은 캐릭터의 원작 재현도가 완성됐다는 의미가 아니다.
- 원인이 없는 감정 질문과 근거 없는 관계 질문은 안전 폴백을 사용하므로 같은 말투 유형 안에서 답변이 반복될 수 있다.
- 1차 평가 시점에는 검증된 `relation` 데이터가 없어 실제 원작 관계도 보수적으로 제한했다.
- 캐릭터별 실제 대화 로그를 이용한 고유 말투 세분화는 계속 필요하다.

## 2차 관계 데이터 반영

- 대표 캐릭터 관계 14건을 방향별 문서로 작성했다.
- 모든 관계에는 작품, 발행처, 공식 출처 URL, 확인된 요약, 캐릭터 관점의 답변 기준을 저장했다.
- 허용 출처 도메인은 Korean Film Council, Marvel, Disney, Harry Potter 공식 사이트, DC로 제한했다.
- `characters_verified_v4` 컬렉션을 새로 구축했다.
  - `profile`: 50건
  - `relation`: 14건
  - 총 64건
- 관계 문서를 찾은 경우 LLM이 자유롭게 관계를 해석하지 않고 검증된 `답변 기준`을 출력한다.
- 관계 문서를 찾지 못하면 캐릭터별 근거 없음 응답을 사용한다.

대표 10명 관계 회귀 평가 결과:

- 총 10건
- 검증 관계 9건: `rag_used=true`
- 미검증 골룸–프로도 1건: `rag_used=false`
- 기대하지 않은 RAG, 폭력·강압 표현, 중복 답변: 0건

평가 원본은 `AI/eval/character_relation_results_v1.json`에 보존한다.

## 단체 대화 1차 정비

기준일: 2026-08-09

확인된 문제:

- 각 캐릭터의 답변이 다음 캐릭터의 대화 이력으로 들어가 말투와 설정이 섞였다.
- 세 캐릭터가 같은 공감 질문이나 조언을 반복했다.
- 관계를 이미 설명한 뒤 2라운드에서 같은 관계를 과장해 다시 말했다.
- 영화 추천 후속 반응에서 목록에 없는 설정과 캐릭터 관계를 생성했다.

반영한 수정:

- 1라운드 답변에 1:1 대화와 동일한 말투·근거·안전 정책을 적용했다.
- 일반 대화는 대표 1명 답변 후 나머지 캐릭터가 반응하는 구조로 변경했다.
- 검증된 관계 질문은 양쪽 답변 후 2라운드를 생략한다.
- 원인 없는 감정 대화와 영화 추천 후속 반응은 캐릭터 말투 유형별 안전 응답을 사용한다.
- API가 단체 응답의 `rag_used` 값을 버리지 않고 전달하도록 수정했다.

검증 결과:

- 로컬 자동 테스트 24건 통과
- GPU API 감정형 단체 대화: 질문 반복 없이 1명 질문, 2명 청취 반응 확인
- GPU API 마석도–강해상 관계 대화: 양쪽 모두 `rag_used=true`, 중복 2라운드 없음
- GPU API 영화 추천: 검색 후보 밖 제목은 나오지 않았으며, 후속 반응의 설정 생성 경로를
  유형별 고정 반응으로 교체했다.

한계:

- 유형별 안전 반응은 안정성을 우선하므로 동일 유형 캐릭터끼리는 표현이 비슷할 수 있다.
- 캐릭터별 실제 대화 로그가 쌓이면 유형별 문장을 캐릭터별 문장으로 점진적으로 세분화한다.
