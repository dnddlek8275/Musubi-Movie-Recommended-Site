# 비회원 채팅 정책 및 후속 운영 계획

작성일: 2026-07-31

## 이번 변경 범위

- 비회원도 자동 추천, 캐릭터 1:1, 그룹 채팅 화면에 접근할 수 있다.
- 비회원 채팅은 IP 기준 한국 시간(KST) 하루 5회로 제한한다.
- 비회원 입력은 메시지당 500자, AI로 전달하는 이전 문맥은 최근 10개
  메시지(각 1,000자 이하)로 제한한다.
- 비회원 AI 응답은 최대 2,000자까지만 클라이언트에 반환한다.
- 비회원 대화방, 메시지, 추천 영화는 DB와 브라우저 저장소에 저장하지 않는다.
  페이지를 벗어나면 화면의 대화 상태가 초기화된다.
- 좋아요, 찜, 최근 추천, 음성 입력(STT) 등 저장 또는 회원 인증이 필요한
  기능은 비회원에게 제공하지 않는다.
- 동시에 처리하는 비회원 AI 요청 수를 제한하여 GPU 서버의 급격한 부하를
  방지한다.

## 회원 정책

- 이번 변경에서는 회원의 일일 채팅 횟수를 제한하지 않는다.
- 회원은 기존처럼 대화방과 메시지를 저장하고 이어서 대화할 수 있다.
- 회원 유료 요금제와 회원별 사용량 제한은 아직 적용하지 않는다.

## 구현상 주의점

- 비회원 일일 사용량은 현재 백엔드 프로세스 메모리에 저장된다. 백엔드를
  재시작하면 초기화되고, 백엔드가 여러 Pod로 늘어나면 Pod별로 계산된다.
- 운영 환경에서 `GUEST_CHAT_TRUST_PROXY_HEADERS=true`를 사용할 때는
  ALB/Ingress를 거치지 않은 백엔드 직접 접근을 차단해야 한다. 그렇지 않으면
  전달 IP 헤더를 위조해 제한을 우회할 수 있다.
- 여러 백엔드 Pod를 사용하기 전에는 일일 사용량을 Redis 또는 DB 기반의
  공용 저장소로 이전해야 한다.

## 배포 마무리 단계의 후속 작업

서비스 배포가 끝나면 먼저 실제 사용량과 비용을 모니터링한다.

- 비회원/회원별 채팅 요청 수와 성공·실패율
- AI 응답 시간, 동시 요청 수, 타임아웃 및 GPU 사용률
- 요청당 토큰·추론 비용과 사용자별 사용량 분포
- 회원 전환율과 반복 사용률

위 지표를 일정 기간 확인한 뒤 무료 회원 한도, 초과 사용 차단 또는 대기,
유료 요금제의 필요성과 가격을 결정한다. 현재 단계에서는 유료 결제 기능이나
회원 채팅 횟수 제한을 선반영하지 않는다.
