# 영화 검색 후보 품질 기준

기준일: 2026-08-10

## 확인된 문제와 당시 기준 데이터

- 아래 품질 문제를 분석한 당시 Milvus `movies_active`에는 32,442편이 저장돼 있었다.
- `Soft Boil`은 평점 0, 투표 0, 관객 수 0, 줄거리 없음 상태였지만
  `가볍게 볼 영화` 검색 후보에 포함됐다.
- 기존 검색은 의미 유사도로 가져온 9편만 CrossEncoder로 재정렬했으며,
  투표 수·평점 신뢰도·메타데이터 완성도를 사용하지 않았다.
- `가볍게`가 공포 영화 줄거리의 `가볍게 넘긴다`와 일치해 공포·범죄·납치 영화가
  추천되는 사례가 있었다.

## 적용 정책

1. 일반 추천 후보를 3배가 아니라 10배까지 가져온다.
2. 일반 추천은 투표 10건 이상 또는 실제 관객 수가 있는 작품을 우선한다.
   후보가 부족하면 원래 후보를 사용해 검색 결과가 비는 것을 막는다.
3. 의미 유사도가 비슷할 때 투표 수, 투표 수로 보정한 평점, 관객 수,
   줄거리·포스터·장르·개봉일 완성도를 함께 반영한다.
4. 투표 한두 건으로 만들어진 10점 작품은 높은 신뢰도로 처리하지 않는다.
5. 최신작 요청은 투표 수가 아직 적을 수 있으므로 신뢰도 필터를 적용하지 않고
   기존 개봉일 내림차순 정책을 유지한다.
6. 분위기·상황 표현을 실제 영화 메타데이터의 검색 개념으로 확장한다.
   - `가볍게`, `부담 없이`, `힐링`: 밝은 코미디·가족·애니메이션·로맨스·모험
   - `감동적인`: 휴먼 드라마·가족·성장·우정
   - `우울할 때`, `기분 전환`: 밝은 코미디·가족·애니메이션·모험·음악
   - `데이트`, `연인`: 로맨스·코미디
   - `아이와 함께`: 가족·애니메이션·모험·판타지·코미디
7. 아이 동반 추천은 미국 `G/PG`, 한국 `ALL/전체관람가`를 우선한다.
   `NR`은 적합성을 확인할 수 없으므로 안전 등급으로 취급하지 않는다. 등급 후보가 부족할 때만
   공포·스릴러·범죄·전쟁을 제외한 가족 장르 후보로 완화한다.
8. 추천 요청은 평점 5.5 이상 후보가 충분하면 그보다 낮은 작품을 제외한다.
9. Milvus의 `genres_list`는 JSON 문자열로 저장되므로 JSON 배열로 파싱해 장르 필터에 사용한다.
10. GPU 서버에서 평가 스크립트를 직접 실행하면 모델이 중복 로드되어 CUDA 메모리가
   부족할 수 있으므로, 실행 중인 `/recommend` API를 통해 회귀 평가한다.
11. 리랭커는 서버 캐시에 있는 모델만 로드해 인터넷 아웃바운드 없이도 재기동한다.
12. 영화 추천 직후의 짧은 피드백은 이전 사용자 요청과 결합한다.
   - `좀 더 가벼운 걸로`: 이전 장르를 유지하고 분위기 조건을 변경한다.
   - `로맨스는 싫어`: 해당 장르를 Milvus 검색 단계에서 제외한다.
   - `좀 더 최신 걸로`: 이전 장르를 유지하고 개봉일 내림차순으로 반환한다.
13. 직전 응답의 `recommended_movies`를 대화 기록에 보존하고, 후속 추천에서는 같은 제목을
    제외한다. 따옴표로 표시된 제목은 구조화 목록이 없을 때의 보조 수단으로만 사용한다.
14. 로그인 사용자는 PostgreSQL의 채팅 기록에서, 비회원은 프론트 메모리의 최근 10개
    메시지에서 `recommended_movies`를 함께 전달한다. 그룹 추천 목록은 첫 AI 메시지에
    한 번만 저장해 다음 요청의 history에 포함한다.
15. 캐릭터가 없는 일반 추천은 자연스러운 해요체로 통일한다.
   - 생성 직전 프롬프트에서 반말·문어체 금지를 다시 명시한다.
   - `영화야`, `딱이야`, `좋아`, `있어` 같은 반말 종결을 생성 후 교정한다.
   - `합니다`, `있습니다`, `입니다` 같은 딱딱한 합쇼체도 해요체로 부드럽게 바꾼다.
   - 처리하지 못한 반말·문어체가 남으면 검색된 영화 제목만 사용한 안전 문장으로 대체한다.
16. 일반 추천은 최종 3편보다 넓은 최대 9편의 후보를 확보한 뒤 메타데이터 중복을 낮춘다.
   최고 순위 후보는 유지하고 2·3순위에서 장르 조합·감독·출연진·개봉 시기의 중복을 감점한다.
   명시적 장르와 최신순 조건은 다양성보다 우선한다.
17. 세 영화에 `가장 잘 맞는 선택`, `다른 결의 대안`, `취향 확장 선택` 역할을 부여한다.
18. 카드별 추천 이유는 장르·배우·감독·개봉일·관람등급·TMDB 평점처럼 응답에 포함된
    구조화 데이터만 사용한다. 일반 추천 답변도 같은 이유와 세 제목으로 직접 구성해 LLM이
    목록 밖 정보나 제목을 만들어내는 것을 막는다. 캐릭터 추천은 캐릭터 말투 생성을 유지한다.

## 실제 API 확인

- `가볍게 볼 영화 추천해줘`
  - 변경 전: 제시카 죽도록 겁주기, 보통의 가족, 나를 믿어줘: 리사 맥비 납치 사건
  - 변경 후: 레이디와 트램프, 야! 러그래츠: 파리 대모험, 로빈슨 가족
- `웃긴 코미디 영화 추천해줘`: 반환 3편 모두 코미디 장르
- `긴장감 있는 액션 영화 추천해줘`: 반환 3편 모두 액션 장르
- `최신 영화 추천해줘`: 개봉일 내림차순 유지
- `우울할 때 보기 좋은 영화 추천해줘`
  - 변경 전: 비버, 더 울버린, 울프맨
  - 변경 후: 드림 쏭, 로빈슨 가족, 밀리언 달러 트러블
- `데이트할 때 볼 영화 추천해줘`: 로맨스·코미디 3편, 평점 6.1 이상
- `아이와 함께 볼 영화 추천해줘`: 가족·애니메이션 3편, 전체관람가 또는 G
- 최종 회귀 평가 8건 모두 통과
  - 전체 응답 시간: 5.246~8.582초
- 후속 추천 실제 API 평가 3건 모두 통과
  - 무거운 액션 → 가벼운 액션: 추천 의도 및 액션 장르 유지, 직전 추천작 제외
  - 로맨스 제외: 반환 3편 모두 로맨스 장르 없음
  - 최신 코미디: 코미디 장르 유지, 2026-04-24 → 04-07 → 03-31 순
- 일반 추천 말투 실제 API 확인
  - 변경 전: `가벼운 액션 영화야`, `기분 전환하기 딱이야`
  - 변경 후: `추천할게요`, `가볍게 볼 수 있어요`, `좋아질 거예요`
  - 데이트 추천도 추천 이유를 유지한 해요체 3문장으로 반환
- 카드 역할·근거 실제 API 확인
  - 데이트 추천: 1순위는 로맨스·코미디, 2순위는 추가 미스터리 장르,
    3순위는 TMDB 7.1점이라는 서로 다른 근거를 반환
  - 답변에 카드 3편의 제목이 모두 포함됨
  - 후속 추천 회귀 3건 모두 통과, 측정 응답 시간 2.279~5.300초

## 회귀 평가

- 사례: `AI/eval/movie_retrieval_cases_v1.json`
- 실행기: `AI/eval/run_movie_retrieval_regression.py`
- 1차 결과: `AI/eval/movie_retrieval_results_v1.json`
- 분위기 확장 결과: `AI/eval/movie_retrieval_results_v2.json`
- 후속 추천 사례: `AI/eval/movie_followup_cases_v1.json`
- 후속 추천 실행기: `AI/eval/run_movie_followup_regression.py`
- 후속 추천 결과: `AI/eval/movie_followup_results_v1.json`
- 실행 예시:

```bash
cd /home/ubuntu/cineverse
./venv/bin/python3 eval/run_movie_retrieval_regression.py
```

응답 속도는 LLM 상태와 동시 요청 수에 따라 달라지므로 한 번의 측정값만으로 성능 목표를
정하지 않는다. 운영 모니터링이 준비되면 p50·p95를 별도로 측정한다.
