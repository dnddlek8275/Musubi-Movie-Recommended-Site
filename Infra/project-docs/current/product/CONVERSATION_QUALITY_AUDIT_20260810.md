# 전체 대화 흐름 품질 감사

기준일: 2026-08-10

## 목적

일반 채팅, 캐릭터 1:1 채팅, 단체 채팅을 실제 GPU AI API에서 순서대로
호출해 의도 분류, 정체성 유지, 관계 근거, 응답 반복과 영화 중복을 함께
점검했다. 백엔드 채팅방과 PostgreSQL에는 평가 메시지를 저장하지 않았다.

## 평가 구성

- 일반 채팅 11건
  - 무무 정체성 및 이름 변경 요구
  - 실제 경험을 한 것처럼 말하는지 여부
  - 감정 대화와 짧은 위로
  - 영화 추천 후속 요청
  - 초성, 무작위 입력, 말줄임표 복구
- 캐릭터 1:1 채팅 10건
  - 마석도, 토니 스타크, 헤르미온느, 골룸, 장첸
  - 감정 대화, 정체성 덮어쓰기, 현재 행동 창작, 검증 관계
- 단체 채팅 5건
  - 두 인물 관계 질문
  - 감정 및 실패 상황
  - 서로 다른 세계관의 캐릭터 조합
  - 단체 영화 추천

실행기와 최종 원본은 다음 파일에 보존한다.

- `AI/eval/run_conversation_flow_audit.py`
- `AI/eval/conversation_flow_audit_results_final_20260810.json`

## 기준선에서 확인한 문제

- 일반 감정 대화가 요청하지 않은 영화 추천이나 자기계발 문구로 이어졌다.
- 캐릭터에게 다른 인물이라고 지시하면 정체성이 바뀌는 응답이 있었다.
- 헤르미온느가 가족·친구와의 현재 계획을 실제 경험처럼 만들었다.
- 골룸과 프로도의 검증 관계 문서가 없어 관계 질문에 RAG를 사용하지 못했다.
- 두 명 단체방의 `둘`, `서로`를 상대 캐릭터 이름으로 해석하지 못했다.
- 단체 영화 추천 결과에 같은 영화 제목이 중복될 수 있었다.
- 실패 상황의 단체 답변에 과장된 격언이나 일반적인 상담 문구가 섞였다.

## 반영한 수정

- 무무의 정체성, 비인간 경험 고지, 감정형 짧은 응답을 안정화했다.
- 캐릭터 정체성 변경 요구를 감지해 원래 이름을 유지한다.
- 현재 계획이나 실제 경험을 근거 없이 만들지 않도록 후처리한다.
- 실패·감정 상황의 과장된 자기계발 문구를 문맥형 응답으로 교체한다.
- 두 명 단체방의 상대 지칭을 실제 참여 캐릭터로 해석한다.
- 단체 영화 후보를 TMDB ID와 제목 기준으로 중복 제거한다.
- LLM 설명이 부정확하거나 지나치게 일반적이면 실제 영화 장르에 근거한
  짧은 추천 문장으로 교체한다.
- Tolkien Estate의 공식 자료를 근거로 골룸→프로도, 프로도→골룸 관계
  문서 2건을 추가했다.

## 배포 상태

- Milvus 활성 컬렉션: `characters_verified_v5`
- 구성: 캐릭터 프로필 50건 + 검증 관계 16건 = 총 66건
- 이전 `characters_verified_v4` 컬렉션은 롤백용으로 유지한다.
- 환경 설정 백업: `/etc/cineverse/character-rag.env.bak-20260810-v5`
- Python API만 재시작했으며 LLM 모델 서버는 재시작하지 않았다.

서비스 예외나 메모리 부족은 아니었으며, 재시작이 없는 상태에서 같은 전체
평가를 다시 실행해 26건을 완료했다.

## 해석과 남은 과제

- 자동 검출 오류 0건은 캐릭터의 원작 말투와 대화 재미가 완성됐다는 뜻이
  아니다. 현재 평가는 정체성 혼용, 근거 없는 관계, 반복, 과장 문구 같은
  명확한 실패를 우선 탐지한다.
- 안전 폴백은 안정적이지만 서로 다른 캐릭터가 비슷한 문장을 사용할 수 있다.
- 실제 서비스 대화 로그가 쌓이면 대표 캐릭터부터 어색한 답변을 평가셋에
  추가하고 캐릭터별 말투 문장을 세분화한다.
- 운영 환경에서는 API 배포와 회귀 평가가 동시에 실행되지 않도록 배포 잠금이나
  상태 확인 절차를 추가할 필요가 있다.

## 2차 실제 대화형 탐색

같은 날 기존 평가 문구와 겹치지 않는 후속 대화 20건을 추가했다.

- 일반 채팅 8건
  - 발표 실패 후 다음 날 재발표 준비
  - 무무의 실제 영화 감상 경험 및 취향 파악 근거
  - `아 진짜` → 상사 업무 추가 → 한숨으로 이어지는 짧은 대화
- 캐릭터 1:1 채팅 8건
  - 마석도에게 장첸 외모에 대한 의견 묻기
  - 토니 스타크에게 상사에게 전달할 실제 문장 요청
  - 헤르미온느에게 공부 미시작 상태의 짧은 계획 요청
  - 골룸–프로도 관계 질문의 표현 변형과 후속 질문
- 단체 채팅 4건
  - 외모에 대한 가벼운 의견
  - 면접 전 짧은 조언
  - 서로 다른 세계관 캐릭터에게 일반적인 친구 갈등 상담
  - `추천`이라는 단어 없이 영화 세 편을 골라 달라는 요청

실행기와 결과는 다음 파일에 보존한다.

- `AI/eval/run_conversation_quality_probe_v2.py`
- `AI/eval/conversation_quality_probe_v2_final_20260810.json`
- `AI/eval/conversation_flow_audit_results_post_v2_20260810.json`

2차 기준선의 자동 플래그는 0건이었지만 수동 검토에서 다음 문제를 확인했다.

- 무무가 영화를 직접 보고 감동한 것처럼 답했다.
- 발표 후속 질문이 이전 문맥 대신 일반적인 휴식 권유로 돌아갔다.
- 토니 스타크가 상사에게 아이언맨 슈트 결함이라고 말하라고 답했다.
- 골룸–프로도 관계 질문의 표현이 달라지면 검증 관계 RAG를 놓쳤다.
- `친구와 다퉜다`를 캐릭터끼리의 관계 질문으로 오분류했다.
- 면접 조언에 슈트·거미줄·전투 비유가 과도하게 들어갔다.
- `영화 세 편 골라줘`를 영화 추천 의도로 분류하지 못했다.
- `유쾌한 영화` 검색이 밝은 코미디 계열 검색 개념으로 확장되지 않았다.

반영한 수정:

- AI의 실제 감상·감정 경험 질문을 결정적 진실성 응답으로 처리한다.
- 발표·면접·공부 미시작 상태와 그 후속 질문을 구체적인 행동 문장으로 처리한다.
- 캐릭터에게 실제 전달 문장을 물으면 세계관 소품을 섞지 않는다.
- 최근 사용자 대화에서 관계 대상을 찾아 관계 질문 표현이 바뀌어도 검증 문서를 검색한다.
- 일반적인 친구 문제의 `친구`를 캐릭터 관계 신호로 사용하지 않는다.
- 가벼운 외모·호감 질문은 관계 RAG나 철학적 조언 대신 짧은 캐릭터 반응을 사용한다.
- `영화 ... 골라줘`를 추천 의도로 분류한다.
- `유쾌한`, `웃긴`, `재밌는`을 밝은 영화 검색 신호에 포함한다.

최종 검증 결과:

- 2차 실제 대화형 탐색: 20건, 자동 검출 오류 0건
- 2차 수정 후 기존 회귀 감사: 26건, 자동 검출 오류 0건
- 실제 GPU API 대화 합계: 46건
- 로컬 단위 테스트: 89건 통과
- API와 LLM 서비스: `active`
- 최종 헬스 체크: HTTP 200

자동 검출 오류가 없더라도 문법적으로 정상인 어색한 비유와 말투는 남을 수 있다.
따라서 이후 평가도 자동 플래그와 응답 원문 수동 검토를 함께 수행한다.
