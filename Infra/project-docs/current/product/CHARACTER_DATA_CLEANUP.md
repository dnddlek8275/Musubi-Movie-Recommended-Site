# 캐릭터 데이터·프롬프트 1차 정비 기록

기준일: 2026-08-08

## 확인된 문제

- 기존 Milvus `characters` 컬렉션은 1,330건이었다.
  - `profile`: 50건
  - `event`: 780건
  - `quote`: 500건
- `event`와 `quote`에는 원작 근거를 확인할 수 없는 인물·사건·대사가 다수 포함되어 있었다.
- 기존 학습 데이터에는 빈 사용자 입력과 캐릭터 구분이 약한 일반 상담형 답변이 포함되어 있었다.
- 프로필의 `avoid` 항목에 다른 캐릭터 이름이 들어 있어, 이름이 검색됐다는 이유만으로 관계 근거가 있다고 오판할 수 있었다.

## 1차 조치

- 기존 `characters` 컬렉션은 삭제하지 않고 보존했다.
- 원본 데이터는 `backups/ai-character-data/character_chunks_unverified_20260808.json`에 별도 보관했다.
- 검증되지 않은 `event`와 `quote`는 서비스 검색 대상에서 제외했다.
- 50명 프로필만 담은 `characters_profile_v2`를 새로 구축했다.
  - 총 50건
  - 고유 캐릭터 50명
  - `data_type=profile`만 존재
  - 중복 캐릭터 0명
- 프로필 임베딩 본문에서는 `avoid`를 제외했다. 금지 예시의 인물명이 관계 정보로 오인되는 것을 막기 위한 조치다.
- 관계 질문은 이름이 우연히 등장한 프로필이 아니라 전용 `data_type=relation` 청크가 있을 때만 근거가 있는 것으로 판단하도록 변경했다.
- 1차로 API 서비스 환경변수를 `CHARACTER_COLLECTION_NAME=characters_profile_v2`로 전환했다.
- 이후 공식 출처로 검증한 관계 14건을 추가한 `characters_verified_v4`로 전환했다.
- 2026-08-10 추가 관계 검증 후 프로필 50건과 관계 16건, 총 66건인
  `characters_verified_v5`로 전환했다. 2026-08-11 운영 환경변수와 실제 서비스
  컬렉션도 `characters_verified_v5`임을 재확인했다.

## 프롬프트·응답 정책

- 50명을 9개 기본 말투 유형으로 나누고 캐릭터별 예외 규칙을 추가했다.
- 일상 대화에는 원작 RAG를 자동 사용하지 않는다. 캐릭터의 말투·태도는 프로필과 말투 프롬프트로 유지한다.
- 감정 표현에 곧바로 훈계하거나 폭력적인 해결책을 제시하지 않는다.
- 근거가 없는 인물 관계는 생성하지 않는다.
- 검증되지 않은 기존 대화 예시는 서비스 프롬프트에 주입하지 않는다.

## 서버 검증 결과

- `/health`: LLM, Milvus, embedder 모두 정상
- `오늘 기분 너무 별론데` → 원인을 묻는 짧은 공감 응답, RAG 미사용
- `강해상이라고 알아?` → 관계를 지어내지 않고 추가 질문, RAG 미사용
- `장첸이 너무 잘생겨보여 어떡해` → 호감 표현의 문맥에 맞는 일상 응답, RAG 미사용

## 남은 작업

- 현재 50명 프로필의 사실 항목도 원작 출처별로 검증해야 한다.
- 대표 관계 14건은 출처와 함께 작성했다. 나머지 관계는 같은 검증 절차로 확장해야 한다.
- 기존 `event`, `quote`, 학습 JSONL은 검증 전 재학습에 사용하지 않는다.
- 대표 질문 평가셋을 캐릭터별로 확장하고 정기 회귀 테스트를 구성한다.
- 캐릭터별 고유 말투의 세부 조정은 실제 대화 로그를 모은 뒤 2차로 진행한다.
