# 박스오피스 순위 자동 갱신

## 동작 기준

- 출처: 영화진흥위원회 KOBIS 일일 박스오피스 API
- 대상: 전날 박스오피스 상위 10개
- 실행 시각: 매일 오전 6시(Asia/Seoul)
- 백엔드가 재시작될 때도 전날 데이터가 없으면 한 번 갱신을 시도합니다.
- 백엔드 Pod가 여러 개여도 PostgreSQL 잠금으로 한 Pod만 갱신합니다.
- 수집한 원본 순위와 영화명은 `daily_box_office_rankings` 테이블에 저장합니다.

## 영화 DB 연결

KOBIS와 TMDB에는 공통 식별자가 없으므로 제목·제작 연도를 확인하고 감독·러닝타임·
제작 국가 중 최소 두 항목까지 일치할 때만 자동 연결합니다. 확정된 연결은
`kobis_movie_mappings`에 영구 저장합니다. 후보가 여러 개거나 근거가 부족하면 임의로
연결하지 않습니다.

KOBIS 상위 10위 작품은 TMDB 투표 수 기준을 면제할 수 있지만 동일성 검증과 성인물
필터는 그대로 적용합니다. TMDB에 없는 작품은 KOBIS 상세정보와 공개 포스터가 있고
청소년관람불가가 아닐 때 `kobis_only` 영화로 최소 등록합니다. KOBIS 전용 영화는
TMDB ID가 없으므로 Milvus 동기화 대상에는 포함하지 않습니다. 이후 TMDB에 등록되면
관리자 확인을 거쳐 기존 KOBIS 매핑을 보강해야 합니다.

## 장애 및 초기 상태

- `KOBIS_API_KEY`가 없으면 외부 호출을 하지 않고 기존 고정 목록을 표시합니다.
- API 호출 실패 또는 빈 응답 시 기존에 저장된 최신 박스오피스를 삭제하지 않습니다.
- DB에 저장된 박스오피스가 있으면 가장 최신 날짜를 표시합니다.
- 따라서 일시적인 KOBIS 장애가 추천 페이지 장애로 이어지지 않습니다.

## 환경 변수

```env
KOBIS_API_KEY=발급받은_API_키
KOBIS_TIMEOUT_SECONDS=15
```

로컬 Docker Compose는 프로젝트 루트 `.env`, Kubernetes는
`cineverse-secrets` Secret에 `KOBIS_API_KEY`를 설정한 뒤 백엔드를 재시작합니다.
KOBIS 키를 설정하기 전에는 실제 일일 갱신이 활성화되지 않습니다.
