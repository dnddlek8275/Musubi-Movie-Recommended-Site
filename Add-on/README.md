# Musubi Add-ons

핵심 서비스와 별도로 개발된 선택 기능과 프로토타입을 보관합니다. 현재
1차 배포의 필수 구성 요소는 아닙니다.

## 구성

- `gpu-monitoring/`: NVIDIA GPU 상태를 수집하고 표시하는 독립 모니터링 도구
- `tts-service/`: OpenVoice V2/MeloTTS 기반 선택형 음성 합성 서비스
- `movie_friend_intro.html`: 메인 React 애플리케이션에 연결되지 않은 인트로 시안

## 현재 상태

- GPU 모니터링은 독립 프로젝트 형태로 구현되어 있으나 운영 인프라에 연결되지 않았습니다.
- TTS는 메인 프론트에 호출 코드가 있지만 운영 서버와 배포 설정이 없습니다.
- 프로토타입 HTML은 제품 빌드에 포함되지 않습니다.

운영에 포함할 기능만 별도 검토와 보안 설정을 거쳐 배포합니다.
