# 일반 대화·추천 후속 운영 회귀 점검 (2026-08-17)

- 운영 엔드포인트: `POST /chat/auto`
- 운영 서버에는 본 문서의 로컬 수정 사항을 아직 배포하지 않음
- 목적: 실제 제보와 다중 턴 입력을 재현하고, 실패가 확인된 항목만 수정

## 운영에서 확인한 정상 항목

- 무무 이름 변경 지시 거부 및 정체성 유지
- 무무의 실제 인간 경험 주장 차단
- 직전 사용자 발화의 영화 제목 회상
- 공포 제외 후 다른 장르 재추천
- 짧은 불명확 입력 `cfr` 복구 안내
- 간달프 정체성 답변
- 토니 스타크의 공포 영화 요청: 반환 카드 3편 모두 공포 장르 포함
- 골룸과 유사한 캐릭터 영화 요청: SF 기반 캐릭터 영화 3편 반환

## 운영에서 재현한 결함과 로컬 수정

### 1. 비영화 추천 요청이 영화 검색으로 오분류

운영에서 아래 요청이 모두 `movie_recommend`로 분류됨.

- 코드 관련 책
- 집중할 때 들을 노래
- 서울 맛집
- 친구와 할 게임
- 웹툰
- 주말 여행지

원인: `추천해줘` 표현만으로 영화 추천 의도를 확정하고, 입력의 명시적 대상보다 영화 제목 부분 일치를 우선함.

로컬 수정:

- 명시적 비영화 대상을 먼저 판별
- 같은 문장에 `영화`, `필름`, `무비`가 명시되면 영화 추천 유지
- 회귀 테스트 추가

### 2. 추천 설명의 잘못된 목적격 조사

운영 출력: `공포을 찾을 때`

로컬 수정:

- 한글 종성 유무에 따라 `을/를` 선택
- `공포를`, `액션을`, `SF를` 회귀 테스트 추가

### 3. 직전 추천 카드 줄거리 환각

입력: `두 번째 영화 줄거리 알려줘.`

운영 출력은 두 번째 카드 `어스`를 가리켰지만, 제공된 카드 줄거리와 무관한 재난·좀비 내용을 생성함.

로컬 수정:

- 최신 구조화 카드의 순번을 결정적으로 해석
- 카드에 저장된 줄거리만 사용
- 줄거리가 없으면 없다고 응답하고 생성하지 않음

### 4. 기존 카드 비교 대신 새 영화 검색

입력: `첫 번째 말고 나머지 둘 중 더 가벼운 건 뭐야?`

운영은 기존 두 편을 비교하지 않고 새로운 영화 3편을 검색함.

로컬 수정:

- 최신 구조화 카드 안에서만 비교
- 카드 장르 정보로 가벼움 점수를 비교
- 선택한 기존 카드를 응답에 함께 반환
