# 캐릭터 스트리밍 경로 일치성 점검 — 2026-08-17

## 범위

- 운영 AI 서버 `POST /chat/stream`에 읽기 전용 요청 9건을 순차 실행했다.
- 서비스 설정, 모델, DB, Milvus 컬렉션은 변경하지 않았다.
- 로컬 수정은 아직 운영에 배포하지 않았다.

## 확인된 원인

프론트의 캐릭터 대화가 사용하는 `/chat/stream`에는 `/chat`의 일부 보호 로직이 연결되지 않았다.

- 오늘의 실제 행동을 묻는 질문에 허구 활동을 생성했다.
- 해결책 없이 들어달라는 요청에 다시 질문했다.
- 최근 대화에서 확인된 관계 대상을 RAG 질의에 이어 붙이지 못해 골룸–프로도 후속 답변이 불완전했다.
- 정체성 변경은 이번 샘플에서는 모델이 거절했지만, 미등록 인물명일 때 결정적 차단기가 동작하지 않는 코드 누락이 있었다.

## 로컬 수정

- JSON 응답과 SSE 응답이 `character_preflight_reply()`를 공유한다.
- 정체성, 정체성 변경, 검증 원작 사실, 현재 활동, 모호 입력을 동일하게 처리한다.
- 미등록 이름으로 바꾸라는 지시도 정체성 변경으로 차단한다.
- `오늘 어디 갔어?`, `요즘 뭐 하고 지내?` 같은 현재 활동 변형도 차단한다.
- 스트리밍 경청 답변이 질문·조언 정책을 위반하면 캐릭터별 경청 폴백을 사용한다.
- 관계 후속 질문은 최근 사용자 대화에서 상대 이름을 찾아 검증 관계 RAG 질의에 포함한다.
- 스트리밍 일반 답변에도 정체성 혼입 제거와 공통 출력 검증을 적용한다.
