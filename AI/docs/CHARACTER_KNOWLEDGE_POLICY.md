# 캐릭터 원작 지식 문서 정책

## 목적

캐릭터 대화에서 관계·소품·사건·능력 등 원작 사실을 물었을 때 확인된 내용만 RAG로 제공한다. 말투와 일반 상담 행동을 정의하는 `character_profiles_ALL_50.json`과 원작 사실을 분리한다.

## 파일 구조

- `character_profiles_ALL_50.json`: 정체성, 성격, 말투, 사고방식
- `data/character_relations_verified_v1.json`: 캐릭터 간 검증된 관계
- `data/character_facts_verified_v1.json`: 검증된 소품, 사건, 능력, 원작 세부 사실

## 근거 등급

- `official_source`: 공식 제작사·배급사·원작 권리자 자료가 해당 사실을 직접 확인한다.
- `user_confirmed_on_screen_detail`: 사용자가 작품 장면을 직접 확인해 제공한 사실이다. 공식 자료가 관계만 보강할 경우 그 한계를 `evidence_note`에 명시한다.

## 작성 원칙

1. 한 문서에 하나의 독립적인 사실만 저장한다.
2. 추측, 팬 이론, 모호한 인물의 속마음은 저장하지 않는다.
3. `summary`는 검증된 사실만, `response`는 해당 캐릭터가 사용자에게 말할 짧은 답변만 담는다.
4. `aliases`는 실제 사용자가 물을 수 있는 유사 표현만 등록한다.
5. `match_groups`가 있는 사실은 각 그룹에서 하나 이상의 표현이 모두 일치할 때만 LLM 호출 전에 확정 답변을 반환한다.
6. 공식 자료가 사실의 일부만 뒷받침하면 전체를 증명하는 출처처럼 쓰지 않는다.
7. 신규 사실은 스키마 검증과 질문 변형 회귀 테스트를 통과한 후에만 컬렉션에 반영한다.

## 반영 절차

1. JSON에 검증된 사실 추가
2. 로컬 스키마·회귀 테스트
3. 새 Milvus 컬렉션을 별도 이름으로 빌드
4. 캐릭터별 질문 카나리 테스트
5. `CHARACTER_COLLECTION_NAME`만 전환
6. 문제 시 기존 컬렉션으로 즉시 롤백

## 현재 범위

- 검증된 관계: 17건
- 검증된 원작 사실: 4건
- 즉답 대상: 우디의 부츠 이름, 캡틴 아메리카 방패 소재, 토르의 망치 이름, 토니 스타크의 아크 리액터
- 관계 보강: 우디와 버즈 라이트이어
- 보류: 골룸의 절대반지, 간달프의 글람드링은 허용된 공식 출처의 직접 근거를 추가 확인한 뒤 반영한다.

전체 50명을 추측으로 채우지 않고, 실제 오류 제보와 고빈도 질문을 기준으로 점진적으로 확장한다.
