# 선호학습 준비 조건

현재 저장소에는 검증된 chosen/rejected 선호쌍이 없다. 따라서 이번 단계에서는 DPO·ORPO를 실행하지 않는다. 자동 생성한 답변을 자동 평가자가 다시 선택한 자료만으로 선호학습을 시작하면 기존 평가 규칙의 편향을 모델에 강화할 수 있다.

선호학습은 다음 조건을 모두 충족한 뒤 별도 실험으로 진행한다.

- 동일 프롬프트에 대한 현행·후보 답변을 블라인드 비교한다.
- 최소 2명의 독립 평가가 일치한 쌍만 사용한다.
- 영화 사실성 또는 안전성 위반 답변은 `rejected` 사유를 함께 기록한다.
- 캐릭터별·시나리오별 쌍 수를 균형화한다.
- `real_user_cases_v1.json`의 문장과 답변은 선호학습 데이터에서 제외한다.
- 선호학습 전후를 같은 고정 평가셋으로 비교한다.

권장 레코드 형식은 다음과 같다.

```json
{"prompt": [...], "chosen": "...", "rejected": "...", "character": "...", "scenario": "...", "reviewers": 2, "agreement": true, "reason": "..."}
```
