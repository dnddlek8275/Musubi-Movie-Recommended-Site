# 영화 개봉일 관리

`movies.year`는 화면의 연도 표시와 연도 범위 필터에 유지한다. 최신순 정렬과 최신성 점수, 개봉 예정작 판별에는 `movies.release_date`를 사용한다. 날짜를 알 수 없는 기존 영화는 `NULL`을 허용하며 임의의 1월 1일로 만들지 않는다.

## 데이터 반영

- CSV 전체 가져오기: `scripts/import_movies_csv.py`가 `release_date`를 함께 저장한다.
- 기존 DB 보강: `scripts/backfill_release_dates.py`는 `tmdb_id`가 일치하고 개봉일이 `NULL`인 행만 갱신한다. 제목, 평점, 포스터 등 다른 필드는 변경하지 않는다.
- CSV에 없는 영화 보강: `scripts/backfill_release_dates_tmdb.py`가 TMDB 상세 API에서 개봉일만 조회한다. `recent` 단계는 지정 연도, `regional` 단계는 한국어·일본어 영화를 처리하며 체크포인트로 중단 후 재개할 수 있다.
- TMDB 관리자 등록: TMDB의 `release_date` 전체 값을 저장하고 `year`를 같은 날짜의 연도로 맞춘다.
- 관리자 직접 등록·수정: 개봉일을 입력할 수 있으며, 입력하면 `year`도 해당 연도로 맞춘다.

## 추천과 AI 반영

백엔드 기본 추천은 DB 등록 시각이 아닌 실제 개봉일로 최신성 점수를 계산하고 미래 개봉작을 일반 추천에서 제외한다. 날짜 미상 작품은 후보에서 제거하지 않되 최신성 가산점은 주지 않는다.

AI의 Milvus `movies` 컬렉션에도 `release_date` 필드가 추가되었다. AI 서버 반영 시 기존 컬렉션을 재생성하고 데이터를 다시 삽입해야 한다. 소스만 배포하고 재색인하지 않으면 새 필드를 요청하는 검색 코드와 기존 스키마가 맞지 않는다.
