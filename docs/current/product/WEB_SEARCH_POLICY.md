# Musubi 외부 웹 검색 운영 정책

## 적용 상태

- 공급자: Tavily Search API
- 검색 방식: `search_depth=basic`, 요청당 최대 5개 결과
- 활성화 조건: GPU AI API 환경에 `TAVILY_API_KEY`가 설정된 경우
- 현재 키가 없으면 기능은 안전하게 비활성화되며 기존 영화 DB·Milvus 추천은 그대로 동작한다.

## 비용 보호

- Musubi 월간 하드 캡: 950회
- 경고 기준: 900회
- 월 기준: 한국 시간(`Asia/Seoul`)
- 950회에 도달하면 외부 API를 호출하기 전에 차단한다.
- 동일 검색어는 기본 6시간 캐시하며, 캐시 적중은 사용량에 포함하지 않는다.
- 네트워크 연결 자체가 실패한 요청은 예약 사용량을 되돌린다. 공급자 HTTP 응답까지 받은
  실패는 실제 과금 여부를 확정할 수 없어 보수적으로 사용량에 포함한다.
- 결제 또는 자동 유료 전환 로직은 구현하지 않는다.

사용량은 GPU 서버의 `/home/ubuntu/cineverse/data/web_search_usage.sqlite3`에 저장한다.
서버 재시작 후에도 유지되지만 서버 디스크를 교체하면 함께 사라지므로 운영 백업 대상에 포함한다.

## 검색이 실행되는 경우

비용과 개인정보 전송을 줄이기 위해 일반 대화나 영화 추천에는 자동 실행하지 않는다. 사용자가
`웹 검색`, `외부 검색`, `인터넷에서`, `구글에서`, `최신 뉴스`처럼 외부 검색 의사를 명시한 경우에만
실행한다. 검색어는 Tavily로 전송되므로 비밀번호·이메일·전화번호 등 개인정보를 입력하지 않도록
UI 안내를 추가하는 것이 좋다.

## 응답과 출처

- 검색 결과 본문은 신뢰할 수 없는 외부 입력으로 취급하고 그 안의 명령은 따르지 않는다.
- 로컬 LLM은 검색 결과에서 확인할 수 있는 내용만 답하도록 프롬프트한다.
- 답변 문장에는 `[1]` 형식의 근거 번호를 붙이고, 프론트는 클릭 가능한 출처 목록을 함께 표시한다.
- 검색 결과가 없거나 공급자 장애가 발생하면 추측하지 않고 검색 불가를 안내한다.

## 운영 확인

- `GET /web/search/status`: 키 설정 여부, 사용량, 잔여량, 경고 상태
- `POST /web/search`: 외부 검색 전용 테스트 API
- `POST /chat/auto`: 명시적 웹 검색 문구가 있을 때만 외부 검색으로 라우팅

필수 환경값은 `AI/.env.example`을 따른다. 실제 API 키는 Git에 올리지 않는다.
